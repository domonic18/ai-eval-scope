接入指南

四种通道，把评估接进流水线

同一把 API Key、同一套评测引擎与租户隔离。服务端系统走 HTTP，智能体客户端走 MCP，本地与定时任务走 CLI——评估完成后可再配 Webhook 回调，结果回流同一可观测平台。

接入方式总览

按调用形态选通道，可按场景混合使用

HTTP API

服务端 / CI

REST 提交评测任务，轮询结果与速览。第三方对接的主力方式：服务端系统、编排引擎、CI/CD 均适用。

POST /api/v1/jobsGET /api/v1/jobs/{id}GET …/overview
适合：课件平台后端 · 自动化脚本 · 流水线卡点

Webhook 结果回调

事件驱动

评估完成后平台主动 POST 你的服务，免去轮询。项目级配置，投递带签名可校验，失败可回退轮询兜底。

webhookUrlX-Webhook-Signaturejob.completed / job.failed
适合：回填业务系统 · 消息通知 · 审核流触发

MCP 接入

智能体客户端

把评测挂成 MCP 工具，让 AI 智能体在对话中直接提交与查询评测，无需手写 HTTP。

list_packagessubmit_eval_job
适合：Claude Code / Cursor 等支持 MCP 的智能体

CLI 直跑

本地 / 批跑

评估器命令行直跑，结果经摄取链路自动回传平台；网络失败入离线队列，联网后重放。

uv tool install "ai-eval-scope[agent,llm]"agent-eval eval
适合：本地联调 · 定时脚本 · 离线场景

五分钟跑通

左侧三步，右侧照敲

01

安装评估器 CLI

一行命令装好评估引擎与交互式工作台（需 Python 3.11+ 与 uv）。

02

配置评测模型

交互式选厂商、贴 API Key，自动连通性测试后写入本地配置。

03

发起第一次评估

交互工作台或脚本化批跑均可；带 --upload 时结果自动上报平台。

完整快速开始
$ uv tool install "ai-eval-scope[agent,llm]"
$ agent-eval models set
✓ 连通性测试通过
$ agent-eval start
# 交互式工作台：描述任务 → 生成评测计划 → 执行 → 报告
# 仓库根目录：postgres + minio + web 一键起
$ cp .env.example .env
$ make docker-up
✓ web 就绪 · http://localhost:9000
# 新建项目 → 签发 API Key → 回到 CLI 配置 .env 即可上报

认证与安全

所有通道共用同一套鉴权语义

Bearer 统一鉴权

一把项目级 API Key 走天下：提交、查状态、取速览。项目归属完全由 Key 决定，提交时无需传项目 ID。

密钥仅明文一次

API Key 仅创建时明文展示一次；Webhook 签名密钥加密存储、不回显，变更写入审计日志。

HMAC 签名摄取

评估器经公私钥对 HMAC 签名推送运行 / 样本 / 约束 / 制品，链路防篡改，密钥不落业务侧数据库。
