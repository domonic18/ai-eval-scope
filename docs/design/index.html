三步接入

从安装到首份评估报告，五分钟

01 / 安装

安装评估器 CLI

一行命令装好评估引擎与交互式工作台：uv tool install "ai-eval-scope[agent,llm]"

02 / 配置

配置评测模型

agent-eval models set 交互式选厂商、贴 Key，自动连通性测试。

03 / 评估

发起第一次评估

agent-eval start 描述任务即得评测计划；带 --upload 结果自动上报平台。

打开接入指南 · 四通道全览
quickstart
$ uv tool install "ai-eval-scope[agent,llm]"
Installed 1 executable: agent-eval
$ agent-eval models set
✓ 连通性测试通过 · 已写入 ~/.agent_eval/llm.json
$ agent-eval start
# 交互式工作台：描述任务 → 生成评测计划 → 执行 → 报告
