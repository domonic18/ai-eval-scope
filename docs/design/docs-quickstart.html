开始使用 · 02

快速开始

更新于 2026-09-22 · 阅读约 5 分钟

环境要求

  • Python 3.11+（评估器运行时）
  • uv — Python 包与工具管理器：curl -LsSf https://astral.sh/uv/install.sh | sh
  • 评测模型 API Key（可选，用于 LLM Judge）
不配置模型 Key 也能跑通规则链路（结构 / 内容校验等 Rule-based 评估器）；LLM Judge 将降级为占位结论，补配 Key 后重跑即可。

安装

一行命令安装评估器 CLI（含评估引擎与工作台）：

terminal
$ uv tool install "ai-eval-scope[agent,llm]"
Installed 1 executable: agent-eval
$ agent-eval --version
agent-eval 0.4.2

按需选择扩展能力（extras）：

extra提供能力
llmLLM 评估器与 Judge（接 OpenAI 兼容 / Anthropic 等厂商）
agent交互式工作台与评测执行域（Agent-Driven 引擎）
vision多模态视觉评估（课件渲染截图判分）
datasets数据集域：下载 / 构建评测数据集

配置评测模型

交互式配置 LLM Key：选厂商 → 粘贴 Key → 自动连通性测试。

terminal
$ agent-eval models set
? 选择厂商 ‣ OpenAI 兼容 / Anthropic / …
? API Key › sk-••••••••••••
✓ 连通性测试通过 · 已写入 ~/.agent_eval/llm.json

第一次评估

进入交互式工作台，用自然语言描述评估任务，Agent 自动产出评测计划并执行：

terminal
$ agent-eval start
… 或脚本化批跑：
$ agent-eval pipeline --package courseware --task "safety_*" --upload
run 20260922_093012 · 24 samples · DR 0.962 · Reward 0.781
✓ 评估完成，结果已上报可观测平台

连接可观测平台

评估结果要进看板，需要两步：起平台 → 评估器指到平台。

terminal
# 平台侧（仓库根目录）：postgres + minio + web 一键起
$ cp .env.example .env
$ make docker-up
✓ web 就绪 · http://localhost:9000

评估器侧在 .env 配置四个变量，此后带 --upload 的评估自动上报：

变量说明
AGENT_EVAL_HOST平台地址，默认 http://localhost:9000
AGENT_EVAL_API_KEY项目 API Key（eval-…，项目设置中签发）
AGENT_EVAL_UPLOAD设为 true 开启摄取（需显式开启）
